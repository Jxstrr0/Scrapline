# Scrapline

A combat-robot builder and career game by Longlight Interactive. Design a fighting robot under a weight limit, prove it on the bench, drive it against an opponent whose build is just as considered, patch it in the pit, read the post-mortem, and build better: from a plywood box in a rented corner of a Haldis machine shop to the televised Scrapline Open. Free, phone-first, plays in the browser and installs as an app.

**Play:** https://scrapline.longlight.games/

Work in progress: see [`docs/SCRAPLINE-PLAN.md`](docs/SCRAPLINE-PLAN.md) for the build plan and [`docs/DESIGN.md`](docs/DESIGN.md) for what is built so far. Developer notes are in [`CLAUDE.md`](CLAUDE.md).
